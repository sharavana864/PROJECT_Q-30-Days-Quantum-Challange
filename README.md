## 📖 About

This repository documents my **30 Days of Quantum Computing Challenge**, where I explored both the theoretical and practical aspects of quantum computing.

Throughout this journey, I learned how quantum mechanics powers computation, implemented quantum circuits using **Qiskit**, explored modern quantum hardware, and studied real-world applications such as **Quantum Cryptography**, **Quantum Finance**, and **Quantum Machine Learning**.

The challenge concludes with a capstone project where I began developing **QuantumVerse AI**, an AI-powered platform for learning Quantum Computing. The current implementation is **Version 0**, with more features planned in future releases.
